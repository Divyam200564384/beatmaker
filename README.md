# Beatmaker

**Play it:** https://codewithdivyam.github.io/beatmaker/

A music toy anyone can use — even a child. Sweep a finger or mouse across the four
coloured lanes (Melody, Chords, Bass, Drums) and each note snaps into an always-on
loop. Everything is in C major pentatonic, so nothing ever sounds wrong.

- Works on phones, tablets and laptops in any modern browser.
- **Share** copies a link that contains your whole song.
- **Save WAV** downloads your loop as an audio file.

## Run locally

```bash
npm install
npm run dev     # http://127.0.0.1:5173
npm test
```

Every push to `main` is tested, built and deployed to GitHub Pages automatically.
